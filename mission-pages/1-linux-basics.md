### Overview
In Today's session, we'll be covering Linux basics.
<br>This will be one of the few sessions where I provide any formal instruction. I believe it will be benificial for everyone to have a decent grasp on Linux prior to working on all of the other missions. So I have decided to dedicate today to learning in a more structured environment.

We'll be setting up an Ubuntu server Virtual Machine using virtual box (as we should all be familiar with it). <br>
If you wish to use a different Linux Distro, you're more than welcome to. However, there's no guarantee that commands or even filesystems will work the same way. So be prepared to do extra research and learning
