# liy-files
A repository full of labs and tasks for learning IT.

LIY site: <a href="https://liy.thorngate.xyz">liy.thorngate.xyz</a>

All of the mission briefs, mission pages (from the LIY site), and downloadable mission extras can be found here and downloaded. 

---

## What is LIY?
LIY (or Learn IT Yourself) is a collection of labs and task outlines for learning IT.
Each lab and task outline are called missions and can range from a beginner friendly guided lab for learning Linux basics, to just a rough outline and objective.
<br>
The idea behind Learn IT Yourself is in the name, rather than just all being step by step labs, it encourages the reader to go and seek out information, rather than just follow a tutorial (as you may have to do in an IT job).


## How to use this repo
As you can see, there are four folders in this repo, each one storing a different type of file.

### Want an easy guide to follow?
Check out our website (above), everything is nicely sorted by mission and all files are together in one place.
 
### Want to explore the repo and work it out for yourself?
Have a poke around and find out.

#### mission-breifs
Contains the guides you'll need to complete the mission

#### mission-pages
These are the raw markdown pages used to render the mission pages on the LIY website, check them out if you'd like!

#### mission-resources
Contains any file downloads neccasary for each mission. Not all missions will require you to download anything, and not all mission resources can be hosted here.<br>
I have done my best to upload them here, however files like an ubuntu ISO won't be uploaded due to the large size (~6GB) and the fact that I don't want take down requests.
